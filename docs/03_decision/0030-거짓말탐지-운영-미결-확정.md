# ADR-0030. 거짓말 탐지 운영 전 미결 사항 확정 — ADR-0029 보완

> **상태: 확정 · 2026-09-15** · 작성 에이전트 도메인(cloverky)
> ADR-0029 의 「정하지 못한 것」①②③ 에 답한다.

## ① 정확도·공정성

**결정: 참고 지표로만 쓴다. 합불 근거로 쓰지 않는다.**

- ADR-0003("AI는 추천까지만")이 이미 이를 보장한다. 추가 검증 없이 배포 가능.
- 담당자 화면에 "참고용 수치입니다. 단독 판단 근거로 쓰지 마세요" 문구를 표시한다.

## ② 지원자 반박 경로

**결정: 지원자에게 보여주지 않는다. 담당자 참고용으로만 표시한다.**

- 반박 경로 문제는 결과를 지원자에게 공개하지 않음으로써 해소한다.
- 서류↔발언 대조(ADR-0026 결정 3)는 지원자가 볼 수 있는 유일한 AI 판단 근거로 유지된다.

## ③ 법·제도

**결정: 현 설계에서 해당 법률 적용 없음.**

- **EU AI Act** · **미국 거짓말 탐지 금지법**: 국내 한정 서비스라 범위 밖.
- **국내 개인정보보호법 자동화 결정 조항**: AI가 단독으로 합불을 결정할 때 적용된다. 우리 서비스는 사람이 최종 결정하므로(ADR-0003) 해당하지 않는다.

## 결과

ADR-0029 의 미결 조건이 모두 해소됐다. 백엔드 통합(에이전트 도메인에서 `LIE_SERVICE_URL` 호출 · 결과 표시)을 시작한다.
